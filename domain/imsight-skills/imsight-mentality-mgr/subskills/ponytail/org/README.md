## Adaptation Map

| Source behavior | Maintained behavior |
| --- | --- |
| Always-on lazy persona; lite/full/ultra/off levels | Twelve independently selectable principles, safe/normal/extreme preset replacement, and no activation by discovery. |
| Persisted mode flag and automatic subagent injection | Project block and agent-local overrides using the mentality manager; independent agent settings and explicit handoffs. |
| Reuse ladder and root-cause tracing | Safe rules with contract checks and an explicit task/edit boundary. |
| One line, fewest files, shortest diff | Readable maintenance reductions; collapse-structure and compact-implementation start at normal intensity. |
| Broad flexibility/dependency removal and speculative-work challenges | Extreme additions subject to required behavior, meaningful defenses, and task scope. |
| Implicit permission to simplify established code | Independent new-code-only/destructive scope; destructive still minimizes impact on task-related infrastructure. |
| Exactly one check, no frameworks, fixed terse output | Proportionate verification using repository conventions and explanations sized to the user's request. |
| Blanket validator/interface/retry deletion examples | Evidence-based replacements with explicit edge cases, consumers, counterexamples, and blocked opportunities. |
| Per-finding deletion tags and mandatory line savings | Compact tagged findings with canonical IDs and supporting evidence; estimates only when justified. |
| Review mode and shipping verdict | One-shot read-only review with selection, boundary, and coverage limits; no shipping approval. |
| Separate audit/debt/gain and benchmark claims | Not imported as runtime capabilities or performance/safety guarantees. |

## Maintenance

Preserve src unchanged. Edit the active references and their shared parent contracts. When importing a different revision, record the origin and retained files explicitly. Check that an isolated mentality-manager bundle works without the archive, upstream checkout, hooks, network, or external installation, and that deployed catalogs retain a complete local source bundle.
