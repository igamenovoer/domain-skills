## Adaptation Map

| Maintained Rule | Original Grounding | Adaptation |
| --- | --- | --- |
| `h1` answer-first | Answer first; present-tense reporting; open on the first real word. | Preserve material qualifications and requested narrative structure; no repeated finding opener on every paragraph. |
| `h2` decision-relevant-detail | Cut to the decision; omit needless words. | Include requested explanation and learning needs; no fixed response length or reduction target. |
| `h3` show-evidence-status | Receipts. | Distinguish observations, inspection, inference, and relevant unrun checks without requiring new validation work. |
| `h4` plain-language | Plain words; avoid stock metaphors. | Preserve exact technical terms and disclose uncertainty rather than hiding it in abstract phrasing. |
| `h5` one-idea-per-sentence | One sentence, one idea. | Treat roughly thirty words as a review cue, not a hard limit. |
| `h6` name-the-actor | Name who acts. | Keep passive wording when the actor is unknown or irrelevant; never invent causation. |
| `h7` structure-for-scanning | Prose by default, bullets earned. | Permit useful two-item lists, tables, headings, and multi-line items without count quotas. |
| `h8` precise-references | Backtick searchable terms; name a thing once. | Respect host file-link syntax and retain full identifiers when a shorter reference would be ambiguous. |

The maintained comparisons adapt the original authentication, SQL, evidence-status, and identifier examples and add illustrative reporting cases. They are teaching examples rather than verified outputs from this repository. The full license notice also accompanies the maintained principle catalog so catalog deployment preserves attribution.
