# Revelio

## Workflow

1. Resolve the subject and mentality using **Inputs and Defaults**.
2. Load the chosen guidance using **Mentality Selection**.
3. Explain the subject in the current reply. Keep the chosen guidance in mind while writing and honor the user's requested depth, language, and format.

For other explanation requests, use your native planning tool to build and execute a plan using the available subject, chosen mentality, and scope of this shortcut.

## Inputs and Defaults

- **Subject.** Explain the topic, question, or material the user supplies. When the subject is omitted, explain the most recent substantive assistant reply before the invocation. If there is no such reply, ask what to explain.
- **Mentality.** An explicit request to use a mentality or flavor takes precedence for this reply. Use Han Style (`human-speak/han-style`) by default. A request that supplies only a mentality still uses the previous reply as the subject.

## Mentality Selection

When Han Style is selected, read its [maintained principles](../../human-speak/references/han-style-principles.md). Keep the reader's context, the answer, the connection between ideas, the meaning of technical detail, and factual precision in mind throughout the explanation.

For another requested mentality, resolve its name and any flavor through the [manager's subskill inventory](../../../SKILL.md#subskills). Read its applicable principles and apply them to this reply. Ask which mentality or flavor the user meant if the explicit request remains unresolved.
