# Turn Brooks Off

## Workflow

1. Resolve current Brooks state from `../references/state.md`.
2. Set `active` to `false`.
3. Retain the complete selected rule set unchanged.
4. Report deactivation, retained selection, and persistence scope.

If the task does not map cleanly to these steps, use the native planning tool to deactivate only Brooks while preserving its retained selection and sibling mentality state.

## Output

State whether Brooks was newly deactivated or already off. Confirm that its selected rules remain available for the next activation.

## Guardrails

- DO NOT clear Brooks rules as a side effect of turning it off.
- DO NOT deactivate another mentality.
