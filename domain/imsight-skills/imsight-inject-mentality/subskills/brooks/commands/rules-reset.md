# Reset Brooks Rules

## Workflow

1. Resolve current Brooks state from `../references/state.md`.
2. Replace the retained selection with all twelve built-in rules.
3. Leave activation unchanged.
4. Report restored codes, current effectiveness, and persistence scope.

If the task does not map cleanly to these steps, use the native planning tool to restore only Brooks' built-in rule selection without affecting activation or sibling mentalities.

## Semantics

Reset restores the built-in selection, not host configuration, another mentality, or an external Brooks Lint configuration file.

## Guardrails

- DO NOT turn Brooks on while resetting its rules.
- DO NOT modify `.brooks-lint.yaml` or any project lint configuration.
