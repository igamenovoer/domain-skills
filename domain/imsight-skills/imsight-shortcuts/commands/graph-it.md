# Graph It

## Workflow

1. Resolve the topic, question, or material using **Subject**.
2. Identify the relationships that matter to the explanation and draw them using **ASCII Diagrams**.
3. Explain the subject in the current reply, placing each diagram alongside the idea it illustrates.

For other explanation requests, use the native planning tool to plan and execute the explanation within the user's scope and the ASCII diagram format.

## Subject

Use the topic, question, or material supplied with the shortcut. When the subject is omitted, re-explain the most recent substantive assistant reply before the invocation. If there is no such reply, ask what to explain.

## ASCII Diagrams

Include at least one diagram in a fenced `text` block using ASCII characters. Use a layout that shows the relevant relationships, such as a flow for a process, a tree for a hierarchy, or labeled arrows for interactions. Keep lines compact and explain any unfamiliar labels in the surrounding prose.

Honor the user's requested language and depth in the explanation. When re-explaining a reply, preserve its material facts, caveats, and source references.
